# 🤖 SmartQueueAI

An AI-powered Queue Management System built using Django and Machine Learning.

---

## 📌 Project Overview

SmartQueueAI is designed to reduce waiting times in hospitals, banks, universities, and government offices by providing intelligent appointment booking and queue management.

---

## ✨ Features

- User Registration & Login
- Online Appointment Booking
- AI Queue Prediction
- AI Triage
- Live Queue Dashboard
- Admin Panel
- Responsive User Interface

---

## 🛠 Tech Stack

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite

---

## 🚀 Installation

```bash
git clone https://github.com/dondapatilakshmiprasanna019-glitch/SmartQueueAI.git

cd SmartQueueAI/backend

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
